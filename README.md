# VisualCast 展馆可视化智能播控系统 · 工程文件结构与交付指南

> **系统定位**：工业级全能展厅智能播控中枢  
> **最新版本**：VisualCast Pro (旗舰工业级)  
> **运行环境**：Windows 10 / Windows 11 (64位) 全兼容，**单文件绿色免安装 Python 环境**  

---

## 一、 快速交付与运行（开箱即用）

所有已编译好的免环境最终交付程序位于 **`dist/`** 目录：

| 文件 / 目录 | 类型 | 功能说明 |
| :--- | :--- | :--- |
| **`dist/VisualCast.exe`** | **终极主程序** | **单文件免安装大屏播控主程序**（内置 Python 3.11 内核、硬解媒体流引擎、全屏硬件加速大屏窗口、Web微服务后台、集群联播与无线投屏引擎）。双击即可秒级起播。 |
| **`dist/一键开启安卓投屏与环境检测.bat`** | 辅助助手 | 纯 ANSI 编码，自动放行 8088/1900 防火墙，自动检测测试机无线网卡并唤起系统级 Miracast 无线连接窗口。 |
| **`dist/config/`** | 配置文件目录 | 存放系统核心持久化配置（`player_config.json`、`cluster_sync_config.json`、`auth_config.json` 等）。 |
| **`dist/media/`** | 素材库目录 | 存放多媒体素材库（`待机/`、`视频/`、`图片/`、`音乐/`、`PPT_PDF/`、`网页_流码/`）。 |

> 💡 **现场部署极速指引**：只需将整个 `dist/` 文件夹拷入任意 Windows 纯净电脑，双击 `VisualCast.exe` 即可直接运行，无需安装任何运行库！

## 三、 核心业务模块职责与设计规范

### 1. 主从机全量设置同步 (Cluster Full Settings Sync)
- **代码位置**：`cluster_sync.py`、`server.py`
- **支持同步范围**：
  - **画面显示**：画面适应比例（适应 contain / 铺满 cover / 拉伸 fill）、横竖屏朝向；
  - **跑马灯字幕**：字幕开关、文字内容、显示位置、字号、颜色、背景色、滚动速度；
  - **音频与播放策略**：系统音量、静音状态、循环模式（文件夹循环/单曲/播完即止）、图片轮巡时间；
  - **待机回退配置**：无人超时待机秒数、待机播放视频、开机默认启动文件夹；
  - **展品元数据**：展品标签、自定义标注与解说词（`custom_media.json`）。
- **三重同步保障机制**：
  1. **主机保存即刻广播**：主控机在后台修改任意参数，系统自动通过 UDP 组播 + HTTP 单播向全网从机直推 `SYNC_FULL_CONFIG`；
  2. **从机上线自动拉取**：从机关机重启或断网重连后，后台自动拉取主控机最新全量设置并覆盖持久化；
  3. **后台一键强推**：管理后台“多机集群联播中枢”提供【⚡ 同步所有设置到从机】按钮，随时可人工强推。

### 2. 系统级无线投屏 (Wireless Cast)
- **代码位置**：`native_cast_server.py`
- **底层架构**：基于标准 UPnP AV 1.0 MediaRenderer 设备描述（`desc.xml`）与 SSDP UDP 1900 组播发现机制；
- **设备兼容**：完美支持华为多屏互动、小米投屏、OPPO、vivo 等安卓手机下拉快捷投屏与 Windows“播放到设备”；
- **体验优化**：投屏连接时自动联动 `close_qr()` 隐藏二维码遮罩，智能解析并补全扩展名（`.mp4`），断开后大屏自动平滑恢复待机轮播。

### 3. 多屏切换与横竖屏适配 (Multi-Screen Display)
- **代码位置**：`system_control.py`、`server.py`
- **物理跨屏调度**：启动时自动枚举系统连接的所有物理显示器，通过 Win32 API 毫秒级将大屏窗口无边框移动至指定副屏；
- **横竖屏自适应**：支持 0° / 90° / 180° / 270° 屏幕旋转与竖屏展牌自适应。

### 4. 智能定时关机与节假日排程 (Scheduled Shutdown & Holiday Engine)
- **代码位置**：`scheduled_shutdown.py`、`server.py`
- **工业级排程**：支持每天、工作日(周一至五)、周末及自定义星期的定时关机；
- **智能节假日感知**：内置中国法定节假日基准库，支持“节假日自动跳过关机 (全天通电保持开放)”、“节假日专属关机时间”或“正常关机”，并支持自由动态添加/删除自定义节假日；
- **安全防误关预警**：关机前 60 秒触发全局紧急倒计时横幅预警，支持后台管理员与大屏端一键【✋ 取消本次关机】守护。

## 四、 开发者运维与二次打包指引

若您修改了 Python 源码或前端静态页面，需重新生成免环境单文件 EXE：

1. 双击运行工程根目录下的 **`打包播控主程序.bat`**；
2. 脚本将自动调用 PyInstaller，依据 `VisualCast.spec` 规范完成依赖与资源的打包；
3. 打包产物将自动更新输出至 **`dist/VisualCast.exe`**；
4. 将 `dist/` 目录拷贝至测试机即可验证。
